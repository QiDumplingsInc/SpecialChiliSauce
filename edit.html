Edit mode 编辑模式

Edit mode lets you reword gallery text in this browser and download a file for a reviewer to apply; on its own it changes nothing on the live site. 编辑模式让你在本浏览器中修改画廊文字并下载补丁文件交给审核者；它本身不会改动线上网站。

Edit mode is off in this browser. 编辑模式在本浏览器中处于关闭状态。

Edit mode is on in this browser. Turning it off keeps any edits you have not submitted yet. 编辑模式在本浏览器中已开启。关闭它不会丢失你尚未提交的修改。

This browser blocks site storage, so edit mode will cover only the page this link opens. 此浏览器阻止了站点存储，因此编辑模式只在此链接打开的那一页有效。
